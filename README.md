# Split Rhythm

A browser-based, strict two-hand rhythm practice prototype. Open `index.html` in a modern desktop browser, calibrate with eight taps, then start practicing.

- Left/right independent key mapping
- 2:3, 3:4, and 4:5 polyrhythm visuals
- Hand-specific guide and response sounds
- Strict ±25 ms Perfect judgment and per-hand statistics
